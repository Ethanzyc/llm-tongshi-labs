# 功能规格 · parseCsvLine（CSV 单行解析器）

> 本规格是「场景 B 全规格」的完整原文（prompts/b.txt 与此逐字一致）。
> 场景 C 用的规格删掉了最末「接口契约」一节（prompts/c.txt），其余相同。

## 目标

实现一个函数：把 CSV 表格的**一行**文本解析成字段数组。只处理单行，不处理多行文件与表头。

## 接口契约

- 语言：JavaScript（Node 18+，ESM）。
- 函数名与签名：`parseCsvLine(line: string): string[]`。
- 导出方式：`export function parseCsvLine(...)`。
- 只输出这一个函数的实现代码，不要附带测试代码、示例或解释。

## 解析规则

1. 逗号 `,` 是字段分隔符。
2. 被成对双引号 `"` 包裹的段落属于同一个字段：其中的逗号不算分隔符。
3. 字段内的双引号写成两个连续双引号 `""`，解析时还原为一个 `"`。
4. 带外层引号的字段解析后去掉引号；不带引号的字段原样保留（不加分也不去空格）。
5. 相邻逗号之间是空字段，必须保留为空字符串。
